# Sound Assets

Place the following audio files in this directory:

- `shotgun.mp3` - Shotgun cocking sound (for Quick Snipe)
- `alert.mp3` - Alert notification (for triggers, warnings)
- `rug.mp3` - Rug pull detection sound
- `buy.mp3` - Buy transaction sound
- `sell.mp3` - Sell transaction sound
- `sniper_ready.mp3` - Sniper ready/armed sound

## Recommended Sound Sources

- FreeSound.org
- Zapsplat.com
- YouTube Audio Library
- Custom recordings

## File Requirements

- Format: MP3
- Sample Rate: 44.1kHz
- Bitrate: 128-192 kbps
- Duration: 0.5-2 seconds (short and punchy)
- Volume: Normalized to -3dB peak
